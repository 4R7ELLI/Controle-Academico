# Programa Controle Acadêmico

Sistema desenvolvido para facilitar a rotina escolar, centralizando o cadastro de estudantes e o acompanhamento de desempenho em um só lugar. O projeto busca tornar a gestão de notas mais ágil, prática e acessível no dia a dia.

## Funcionalidades
- Cadastro e gerenciamento de alunos.
- Cálculo automático da média individual e da média geral da turma.
- Atualização rápida e simplificada de boletins.
- Consulta ágil de dados e informações acadêmicas.
